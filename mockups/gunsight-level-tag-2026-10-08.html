GUNSIGHT LEVEL TAG

Design reference, 2026-10-08, level tag: digits only, elite and rare icons
Bug from play: the level tag is too wide and reads L9 where only the number is needed; elites and rares need an icon, and the tag should size to its content. Everything below is drawn from the real code (GunsightTags.lua: plate 68 x 15, chamfer 5, Mononoki Bold 11, pink outline, white text, gold classification word) and the shipped palette. Three icon concepts, all at true scale (1x) and 3x, plus a pixel loupe of each at the size the game draws them.

01 WHERE IT SITS

The tag is seated on the target box's top-left corner, its top 8 px above the box (RISE), 1 px in from the left edge. It grows to the right only, so it never reaches the KICK tag. Left, today's plate (fixed 68 wide, "L9"). Right, the proposal (digits only, plate hugs the text). Both at 1x and 3x.

02 STATES, ALL THREE CONCEPTS

Rows are the target's classification and level. TODAY is what the code draws now. A, B and C are the three icon concepts. Each cell shows the tag at 1x (left, the real size) and 3x. The cyan number is the plate width in px. Plate width = 5 pad + icon + 3 gap + digits + 5 pad, digits 6.2 px each (Mononoki advance 575/1024 em at 11 px), minimum 15 (the plate height, so the chamfers never collapse).

03 THE THREE ICON CONCEPTS

Reference meaning from Blizzard: gold dragon = elite, silver dragon = rare, silver dragon in the gold frame = rare elite. Kept here as a colour rule, reinterpreted as shapes. Gold part = elite, silver part = rare, so a rare elite carries both. Silver is the shipped steel #8d93a6 mixed 55% to white (#cccfd7); steel itself is too dim at 11 px on the dark plate, so a silver token would be new. World boss and skull-level mobs get a red skull.

Secret in combat?NEEDS IN-GAME PROBEThe dump was taken out of combat. No repo note records UnitClassification or UnitLevel in combat. The code is already safe either way (IsSecret guards, SetFormattedText for the level). Design consequence if secret: the level can still be drawn (it goes to a format string) but the icon cannot be chosen (a string compare) and the plate width cannot be measured from a secret. Plan: if either is secret, keep the last known icon and reserve two digits of width.
