Cast Bar V2 Fills

Eight ways to fill the same bar. The layout is fixed from the reference image: a chamfered frame, spell icon, fill run, cast time, and a name tab hanging under the left side. Scrub the slider or press play, then pick a letter.

Fill behavior. Smooth fills the leading segment partway. Ignite (default) keeps every segment whole: it stays dim until the cast passes its start, then strikes up with an old neon flicker and settles lit. F is always smooth. A full cast holds lit, then fades. Interrupt plays a power outage. Ignite style sets how busy the flicker is: Calm, Medium (default) or Busy.

Beacon

Player on top, its tab hanging at the left. Target below, its tab rising at the right. The target runs its own 3.0s cast and starts partway in, so the two lock-ins land apart on the first loop and drift after that, like real casts. The bridge sits between them as raw bot pixels; the gap is worked out from the tabs and the bridge, and the minimum above can only raise it. The Beacon toggle swaps the bridge layout. Two corners puts a magenta marker top left and a cyan marker bottom right. The bot finds the beacon once, when it starts (calibration runs on the first frame and is then cached), and you are not casting then, so the cyan chevrons nearby never compete. The bot also only looks for the cyan marker at the spot the magenta beacon predicts, which covers the data pixels, since they can show any color. The bot would measure scale from the corner to corner distance, a much longer ruler than one strip, so each marker only needs 3 dots. Horizontal is the same 6 dot strip turned sideways. Two corners and Horizontal are proposals that need the bot's beacon finder changed. Vertical is how it works today.

Stack options

Three ways to lay out the player bar, bridge and target bar. Each is a live copy of the stacked card on the same loop. The faint dashed box around each stack is its overall footprint, tabs included, and the dashed rectangle inside the bridge is that bridge's keep-out. The gap is player frame bottom to target frame top, and each bridge keep-out stays at least 12 units from a bare frame so no bar effect reaches it.

A. Keep tall gap

About 270 wide bars (a base of 260, grown a few units so a whole number of chevrons fits with no spare room; the exact width is in the caption below). Player tab hangs under the left, target tab rises at the top right, so both tabs sit in the gap and the bridge is cleared below one and above the other.

B. Wider bars

About 450 wide bars (a base of 440, grown a few units so a whole number of chevrons fits; the exact width is in the caption below), same height and segment size, so there are more chevrons. The tabs stay near the outer ends. The vertical bridge fits between the tabs, so the gap is just the bridge plus margins. A wider bridge can reach under a tab, which is then cleared by its height plus 4: Horizontal reaches one tab here, and with the page font loaded Two corners clears both tabs by about a unit.

C. Tabs on the outside

About 270 wide bars (a base of 260, grown a few units so a whole number of chevrons fits with no spare room; the exact width is in the caption below). Player tab rises above the left, target tab hangs under the right, so the gap holds only the bridge.

Pet slot rings

Click a slot to toggle autocast.

Each slot is drawn at the 30px design size and shown at 3x. The green ring uses the addon autocast color. Turning it on uses the same ignite flicker as the bar segments. Turning it off uses the same outage as the Interrupt button, and the Interrupt length input sets how long it takes.

Notes. Lit color runs violet to hot pink across the run (G and H default to cyan, see Chevron color), with a cyan leading edge in Smooth mode and at the last lit segment in Ignite mode. Unfilled segments are dim cyan: flat for A, C and H, outlined for B, D, E and G. In channel mode the bar starts full, lights right to left, then drains toward the left and ends empty, so there is no lit hold: a channel that runs out plays the Channel finish during the completion hold (cut to 200 ms with reduced motion, and Last ember's flare lasts at most 0.6 s), nothing plays if Channel finish is None or the hold is under 0.08 s, and an interrupted channel plays the outage. Use 2x zoom to check pixel edges. With reduced motion on, segments snap on, the hold still happens, the completion fade is instant, and an outage (cast bar or ring) becomes a plain dim over the same length.
