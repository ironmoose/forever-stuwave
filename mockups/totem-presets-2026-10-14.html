TOTEM PRESETS

Design draft for Parker, 2026-10-14, Shaman

Parker asked for presets: "a healing preset, an oh shit button preset, etc". Three distinct ways to give the totem tab that, each drawn the same way: the tab at true size in six states, a 3x zoom, the editing flow, and the settings rows. Everything is built inside what the client lets an addon do (box below). All preset contents are EXAMPLES the player renames and refills, not recommendations. Icon art is a stand in. A pink frame is a mockup device that means "in combat", it is not drawn in game.

FEATURE LIST (ALL THREE CONCEPTS)

  • A preset is a name (up to 8 letters), one totem per element, and a drop order. An element can be left out: switching keeps that button as it is and stepping skips it. Up to 4 presets per character.
  • Switch with one click out of combat. The four element buttons and the Gunsight poles follow at once.
  • Switch in combat is allowed but queued: it shows as waiting and applies the moment combat ends.
  • Set link: the active preset is written into the native set, so SET DROP (Call of the Elements) drops it in one cast. One preset can be pinned to the second set, so Shift on SET DROP (Call of the Ancestors, level 30) drops it with no switching, even in combat.
  • Step drop: one press drops the next totem of the preset, four presses lay all four, with a visible progress count. Works before level 20, where no sets exist.
  • Partly locked presets use what the character knows and say what is missing. Empty presets are dotted.
  • Editing (create, rename, fill, reorder, delete) only out of combat.
  • Every cue is optional: the waiting pulse, the applied flash and each sound have their own off toggle. Settings explain themselves with the circled ? tooltip, no helper lines.
  • Keybinds: any new button is appended after the six existing ones, so saved binds never move.

WHAT THE GAME LETS US DO

  • Change what the four element buttons cast, out of combat (the same attribute sync the picker uses today).
  • Write a preset into native set 1 or set 2 with the pick call, out of combat. After that SET DROP and Shift+SET DROP drop it in combat with one press (3 s cast, pushback applies).
  • A dedicated step button with a fixed script written before the fight: each press drops the next totem. Needs a live check: secure macro casting on this client is unverified.
  • Draw progress from our own cast events and the live totem duration objects. Both are readable in combat.
  • Hold a switch made in combat and apply it at combat end, with a visible waiting cue.

WHAT IT DOES NOT LET US DO

  • Change any secure button in combat. A switch made in combat can never take effect before the fight ends.
  • Drop four totems with one click before level 20. One click is one cast and totems share the global cooldown.
  • Edit a preset in combat, or write the set slots in combat.
  • Know if a step totem was killed. The fixed script only knows which step it is on, so a lost totem is re-dropped from its element button. The script restarts after combat or a pause. A stun or failed cast can leave the step off by one until that restart (old forum reports, unverified here).
  • Read which totem stands while in combat (names are hidden). We use our own cast record.
  • Use a third native set yet: Call of the Spirits is level 40 per ForeverDB, above the beta cap of 30 (unverified, one Blizzard article orders 30 and 40 differently).
Words like macro are design notes on this page only. Client text says preset, set and drop.

Q // OPEN QUESTIONS

  • Live check (blocks step drop): does a secure macro with a step sequence cast totems on this client, does it advance only on a successful cast, and what does its reset option accept?
  • Live check (blocks set pinning): is the pick call accepted for the second set slots, and does writing set 2 leave set 1 intact? The picker only edits set 1 today.
  • Call of the Spirits: ForeverDB says level 40, above the cap. Treat set 3 as absent until a level 40 character exists.
  • Limit of 4 presets: chips fit 4 in concepts A and B, and the dial in C could carry more. Keep one limit for all?
  • Left out element: keep the current pick (drawn here) or clear the button?
  • Half laid step set: what restarts it: combat end only, or also a pause of a few seconds (6 s drawn in the tooltips as a placeholder)?
  • Concept C width: the tab grows from 6 to 8 cells (264 to 350 px) and the buff tab slides right. Acceptable?
  • Panic preset in A and B: they have no always armed panic button. Pinning it to the Shift set (level 30) is the only no switch route. Enough?
