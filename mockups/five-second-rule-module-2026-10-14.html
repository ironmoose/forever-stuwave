FIVE SECOND RULE MODULE

Design reference, 2026-10-14, all mana classes
One class neutral cue for the five second rule (FSR): after you spend mana, your Spirit regen is suspended for five seconds. Three concepts that differ in form and metaphor, not recolours: A, Hourglass (target side, a Gunsight area), B, Lock (player side, docked under your left rail) and C, Cells (player side, a second shoulder tab on the Console, like the Shaman buff tab). All three draw the same five feasible cues and nothing else. Research: five-second-rule-research.md, 2026-10-14, client build 16001.

// DECIDE

1. PLACEMENT

ATarget side. Hourglass in a Gunsight area. Hides with no target, so it is blind exactly when you drink between pulls. BPlayer side. Lock docked under your left rail. Always visible, no click. CPlayer side. Cells as a Console shoulder tab. Always visible, tooltip on hover, same chrome as the buff tab. The research says the rule matters between pulls too, which favours B or C. A is the one that sits inside the gunsight.

2. MODULE ID

A needs a new Gunsight module id (for example fsr). The class slot is already owned per class (Paladin seals, Shaman, Warlock, Rogue, Druid), so the cue cannot ride on it. It touches MODULE_IDS, the area get and set, and the config row, and it needs an area the player picks (lower or upper). B and C need no Gunsight id. B is a piece on the player side. C is a Console shoulder seat, placed after the class tab if the class has one.

3. DEFAULTS

Pulse on, sound off, both with their own toggle. Idle fade: the cue drops to the dim idle look a few seconds after regen resumes. Wording: the client says "five second rule" and "regen" only. Nothing that reads as automation.
