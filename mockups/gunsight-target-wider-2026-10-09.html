GUNSIGHT TARGET BOX, 20 PX WIDER

Design reference, 2026-10-09, target info box 114 to 134 wide, seat unchanged
The idea: grow the target box 20 px to the right (left edge, tape and cast tile stay put) so the name line, the cast line and the target of target plate (with the chosen reticle A) get more room. Everything here is drawn from the real code and the v7 HUD: Gunsight.lua (BOXR, DOT_AX, AREA, MYBUFFS), GunsightBoxes.lua (name fit), GunsightTags.lua (chip and ToT plate), GunsightTape.lua (KICK tag). 1x is one image px per screen px; 3x is triple. At rest the target box and the modules that follow it are steel; a kickable cast turns them pink.

01 GEOMETRY AND FIT RULES USED

Target box x 1152..1266 (114), grown 8 px up so y 416..480, chamfer 8, fed by G.BOXR. Proposed x 1152..1286 (134). Name line (line 1): base 14, floor NAME_FLOOR 11, width w - 14 = 100 now, 120 proposed; a name too wide at the floor is cut by the FontString ellipsis (three dots). Cast line (line 2): base 14, floor 6, same width. HP chip dx 4, w 32 (unchanged). ToT plate dx 41, h 15, 7 px up over the box bottom, 4 px short of the box right edge: 69 now (no icon, label 63), 89 proposed, with the 9 px pink reticle A and its 2 px gap: label = 89 - 3 - 3 - 11 = 72. ToT fit: shrink from 11 to the floor 8; a name that would not fit even at 8 is written as initials first ("Bartholomew Oldlight" becomes "B. Oldlight"), then shrunk again from 11. KICK tag rides the box top right corner (kx = BOXR.x + BOXR.w - 40), so it moves with the new edge. Mononoki advance 575/1024 = 0.5615 em per character, so every width below is characters x 0.5615 x size, whole pixel sizes. Assumptions: rails are drawn as wide as the fitted name (capped at the inner width); tag outlines stay pink at rest (the code never tints them); the level tag is drawn as crown plus two digits.
